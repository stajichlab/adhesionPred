## 2. What the tools are (do not misname them)

- The shipped CLI is **step 1: surface glycoprotein prediction** (package `surface_glyco`,
  ESM-2 embeddings plus logistic regression). It is not an adhesin predictor. About 12% of its calls
  on *S. cerevisiae* S288C were known adhesins in the 2026-09-27 review.
- **No trained model ships.** The two old pickles were deleted. Version 0.2.0 is cut only after a
  validated surface-glycoprotein model exists.
- The plan has three steps: (1) is the protein surface or secreted; (2) which adhesion mechanism
  (2a repeat, 2b small secreted, 2c hydrophobin); (3) purpose layers (antigen, biofilm). See the

Other assessments from this period (full reports in section 6):

- **PRA3 (CIMG_02492).** The full-length AlphaFold model has a 67 aa confident core with 11 Cys.
  No pdb100 hit reaches TM 0.5 (best 0.39, LDDT 0.40 or lower). The truncation hypothesis is not
  supported. This does not show that PRA3 has no fold (mean pLDDT 62.2). All 12 Cys pair in the
  model; that is a model property.
- **PF28404 family.** Not specific to *Coccidioides*. 408 proteins in 283 of 831 proteomes searched;
  68 of 78 Onygenales proteomes have it. The four *Coccidioides* paralogs fall in four tree groups
  that are older than the genus. Function unknown. Orthology not inferred.
- **SOWgp.** The 39 strains with no gene model have normal read depth, so the "8% absent" is a
  gene-model gap. Three of six SOWgp loci in the long-read assemblies have split gene models. The
  numbers come from the PR #43 commit message; they were not re-checked.

## 7. How to work here

**Owner's working style** (from the owner, 2026-10-01):
- New work goes spec, then plan, then an independent review (a different model) before code.
- Execute with an implementer and an independent reviewer per task, then a whole-branch review.
- When asked for questions, ask one at a time with a recommendation.
- Work on branches and open PRs. **Do not merge, cut releases, delete data or branches, or run
  large SLURM jobs without a go-ahead.** The owner names what to merge.
- Writing: Simplified Technical English. No inflated claims. State when data is missing.
- Accuracy gates are set after measurement, never before.

**Commands and environment**
- Push over HTTPS: `git push https://github.com/stajichlab/adhesionPred.git <branch>`. SSH to
  GitHub is denied from this shell. A remote branch delete was blocked by the permission classifier.
- Tests: `PYTHONPATH=src python3.12 -m pytest tests/step1_compare` (about 5 min; the tests import
  `surface_glyco`). Unit tests: `tests/surface_glyco`.
- Lint: CI uses ruff 0.3.5 (the pre-commit pin). A newer local ruff reports other findings. Use
  `uvx ruff@0.3.5 check .` or `pre-commit run`. The pre-commit hook may reformat files and fail the
  commit once. Stage and commit again.
- Golden metrics file: regenerate with `PHASEC_WRITE_GOLDEN=1` and compare the diff before
  committing. Only intended paths should change.
- Stacked PRs: merge each into `main`, or retarget the base. PRs #33 to #35 merged into their parent
  branches and did not reach `main` until PR #38; one commit pushed after a merge was missed
  (PR #41).
- SLURM (UCR HPCC): scripts start with `#!/bin/bash -l`. Use `$SCRATCH` for temp files. Never use
  `BASH_SOURCE` in SLURM scripts; pass paths by environment. Foldseek and the AVX2 MMseqs2 build run
  on `highclock` (constraint cleared) or `epyc` with `--constraint=ryzen`. Size fan-out jobs toward
  1 to 1.5 hours each. Step 1 Phase B used partition `exfab` with GPUs.
- Python: 3.12. SLURM scripts call `/rhome/jstajich/.conda/envs/adhesionPred/bin/python`.
  Mycelium scripts need `/usr/bin/python3.12`.
- Modules used: `hmmer/3.4`, `mafft/7.505`, `trimal/1.4.1`, `iqtree/2.2.2.6`, `signalp/6-gpu`,
  `predgpi/202001`.
- Large text outputs are compressed (`.gz`; `.zst` for internal intermediates).
- `analysis/cocci_repeats/unit_genomes.tsv` is git-ignored and lives only in the main checkout.
  Scripts that read it need an explicit path in a worktree.

**Known traps added in this period**
- UniProt E9CRM7 (PRA3, *C. posadasii* Silveira) is an inactive entry. Use UniParc UPI0001A7D0B4.
- A shell `pkill -f` whose pattern appears in its own command line kills the calling shell.
- `xargs -0` with `tr '\t' '\0'` leaves a trailing newline in the last field. Use `awk` with
  `printf "%s%c"` to build NUL-separated input.
- Ruling labels in the Phase C spec are shared. C-16 is compare-with-rules; C-17 is the C grid.
- Standing rules and traps of `HANDOFF-HPCC.md` sections 5 and 6 apply (name a tool for what it
  detects; state clade scope; absence is not established by a missing call; PF10528 is GLEYA, not
  Flo11; UniProt's *C. posadasii* reference proteome is the ΔSOWgp strain C735).
