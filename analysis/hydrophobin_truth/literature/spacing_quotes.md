# Quotes from Linder 2005, Sunde 2008 and Wessels 1994

Rules for this file.
- Every quote was read in the PDF supplied by the owner. The PDFs are in `to_import/hydrophobins/`.
- Page numbers are journal page numbers. For Linder, PDF page n = journal page n+876. For Sunde, PDF page n = journal page n+772. For Wessels, PDF page n = journal page n+412.
- Unit for spacing: residues between two cysteines.
- Result for all three papers: **no paper gives a numeric cysteine spacing in its text** (no "C-X5-9-C" style pattern, no residue counts for the gaps between Cys). Sequence alignments are in figures (pictures). I did not transcribe any residue from a picture.
- How I read the PDFs. The Read tool could not render PDFs here (pdftoppm missing). I used Ghostscript 9.27 (`txtwrite` and PNG render). Text layers of Linder and Sunde are clean. The Wessels text layer is OCR with many typing errors (examples: "faimly", "hte", "ifrst", "pattenrs"). In Wessels quotes below I corrected these OCR errors only. I did not change any word. Corrected quotes are marked "(OCR corrected)".
- Two-column layout was rebuilt by x-position. A caption that crosses both columns was rejoined by hand. These are marked "(caption rejoined)".

## 1. Linder 2005, FEMS Microbiol Rev 29:877-896 (PMID 16219510)

Summary of what the paper has on each topic.

| Topic | Result |
|---|---|
| Numeric Cys spacing | None in text. Fig. 2A is a schematic of the Cys order (C, CC, C, C, CC, C) with disulfide arcs. It has no residue counts. |
| Consensus pattern | Only the qualitative pattern (eight Cys, 2nd and 3rd adjacent, 6th and 7th adjacent). |
| Class I vs II | Class by hydropathy (Wessels). Class II "most uniform" in sequence and loop lengths. Class I longer first loop. Subgroups Ia (ascomycete) and Ib (basidiomycete) are defined by phylogeny. |
| Signal peptide | None. The text does not mention signal peptides. Amino termini are said to be excluded from alignments. |
| Mature length | "about 10 kDa". No residue range. |

## 3. Wessels 1994, Annu Rev Phytopathol 32:413-437 (doi 10.1146/annurev.py.32.090194.002213)

The PDF is a scanned copy with an OCR text layer. The hydrophobin section is journal pages 422 to 430 ("Hydrophobins in morphogenesis and pathogenesis"). The review has no abstract. Page 416 and the keywords mention hydrophobins only in passing.

| Topic | Result |
|---|---|
| Numeric Cys spacing | None. The text says "eight cysteine residues characteristically spaced" and "the spacing of the eight cysteine residues" without numbers. |
| Consensus pattern | None as a string. |
| Class I vs II | Defined by the hydropathy pattern (Fig. 1), after alignment on the Cys. Cerato-ulmin and cryparin are class II. Solubility of aggregates is described in the text. |
| Signal peptide | Yes. "signal sequences for secretion". Fig. 1 caption says the hydrophobic N-terminus serves as signal sequence and arrows mark mature N-termini when known. |
| Mature length | "about 100 amino acids" for the family. No finer figure. |

Evidence note for protein lists. Wessels p. 425 says that among the class I proteins only Sc3 and Sc4 were identified as proteins in 1994. The rest were gene products. This is the earliest statement in the supplied papers on protein-level evidence.
